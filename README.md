# Password Manager

A simple password management application developed using Python and SQLite.

## Features

- Add new passwords
- View saved passwords
- Search passwords by website
- Delete passwords
- SQLite database integration

## Technologies Used

- Python
- SQLite3

## Project Structure

```text
Password-Manager-Python/
│
├── main.py
├── database.py
├── passwords.db
└── README.md
```

## How to Run

1. Clone the repository

```bash
git clone https://github.com/kardelenn34/Password-Manager-Python.git
```

2. Navigate to the project directory

```bash
cd Password-Manager-Python
```

3. Run the application

```bash
python main.py
```

## Example Menu

```text
1 - Add Password
2 - View Passwords
3 - Search Password
4 - Delete Password
5 - Exit
```
